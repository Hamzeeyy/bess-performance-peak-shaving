# BESS Performance Optimization for Peak Shaving 🔋

**Associated with:** Åland University of Applied Sciences  
**Domain:** Energy Storage Systems (BESS), Data-Driven Optimization, Energy Economics  
**Tools Used:** Python (Pandas, NumPy), Data Analysis  

---

## 📌 Project Overview
Battery Energy Storage Systems (BESS) are critical for mitigating peak load pricing and stabilizing industrial energy demand. This project involves developing a Python-based computational model to process synthetic grid data, analyze State-of-Charge (SoC) cycles, and calculate degradation metrics to minimize overall peak power usage costs.

---

## 🔑 Key Features & Technical Scope
- **Data Pipeline & Processing:** Built robust data structures using Pandas and NumPy to ingest and clean high-resolution synthetic grid consumption records.
- **SoC Optimization Modeling:** Developed dispatch algorithms to optimize battery charge/discharge cycles during peak demand intervals.
- **Degradation & Cost Analytics:** Quantified battery cycling wear-and-tear against electricity tariff structures to evaluate financial viability and peak shaving efficiency.

- **Programming & Libraries:** Python, Pandas, NumPy
- **Engineering Principles:** State-of-Charge (SoC) Optimization, Battery Degradation Metrics, Peak Shaving, Energy Economics
